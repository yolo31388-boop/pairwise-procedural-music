# 游戏内程序化音乐生成与音频系统

## 项目描述

游戏内程序化音乐生成与音频系统的bug修复项目。核心模块 `audio/music.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 旋律生成完全没做音乐都是固定的
- 音频合成完全没做只能播放预录的音频
- 音乐理论完全没做不懂音阶和弦节奏
- 自适应音乐完全没做不能根据游戏场景变化
- 音效设计完全没做音效都是重复的

## 运行测试

```bash
python -m pytest tests/test_procedural_music.py -q
```

修复目标：所有 15 个测试全部通过。

## 技术要求

- 纯Python标准库，不引入第三方依赖
- 不修改测试文件
- 保持现有API接口不变
